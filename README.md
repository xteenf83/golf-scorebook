# 나의 골프 스코어북 (PWA)

아이폰 홈 화면에서 쓰는 개인용 골프 스코어북입니다.

- 주소: https://xteenf83.github.io/golf-scorebook/
- 로그인·저장: Firebase (구글 로그인 + Cloud Firestore, 오프라인 저장 지원)
- 배포: `main` 브랜치에 올라가면 GitHub Actions가 자동으로 GitHub Pages에 배포

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면·기능) |
| `firebase-config.js` | Firebase 설정값 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 이름·아이콘 |
| `sw.js` | 오프라인에서도 앱이 열리도록 하는 캐시 |
| `firestore.rules` | Firebase 콘솔에 붙여넣을 보안 규칙 (본인 데이터만 읽기/쓰기) |
| `reference/golf-scorebook-v5.html` | 이전(claude.ai 아티팩트) 버전 원본 |

## 기본 코스
`index.html`의 `DEFAULT_COURSES`(현재 51개)가 기본 코스 목록입니다. 앱이 열릴 때 계정에 저장된 `coursesSeedVersion`이 `COURSES_SEED_VERSION`보다 낮으면 한 번 맞춥니다: 같은 골프장+코스명이 있으면 홀별 파(와 `dist`의 티별 거리)만 덮어쓰고, 없으면 새로 만듭니다. 목록을 바꾸면 `COURSES_SEED_VERSION`을 1 올리세요. 더보기 → "기본 코스 다시 맞추기"로 수동 실행도 됩니다.

## 재미 기능
더보기 → "재미 기능"에서 고스트·홀 브리핑·축하 연출을 각각 끄고 켤 수 있습니다(기본 켬, `users/{uid}/settings/app`에 저장).

- **고스트 매치**: 새 라운드(홀별 입력)에서 `베스트`/`직전 라운드`/`없음`을 고르면, 같은 9홀 코스(courseId)를 친 과거 기록과 홀마다 대결합니다. 전반·후반 순서가 바뀌어도 코스끼리 맞추고, 한쪽 9홀만 기록이 있으면 그 9홀만 비교합니다. 플레이 화면에 `고스트 대비 −1`, 홀 버튼에 이긴 홀 초록·진 홀 주황 점, 라운드 화면에 승패 한 줄. 라운드에 `ghost:{front,back}`로 저장.
- **홀 브리핑**: 같은 코스·같은 홀 기록이 2회 이상이면 홀 카드에 평균·베스트·OB·티샷 미스 방향·3퍼트와 코치 팁 한 줄(규칙 기반)을 보여 줍니다. 눌러서 접기/펼치기.
- **배지**: 저장하지 않고 라운드를 날짜순으로 훑어 매번 계산합니다(기록을 고치거나 지우면 자동 반영). 홈 → 배지. 퍼팅·페어웨이·구질 배지는 기본값(2퍼트·적중·스트레이트)을 바꿔 기록한 라운드만 셉니다. 라운드를 마쳤을 때 새 배지·개인 베스트면 꽃가루와 배지 카드(움직임 줄이기 설정이면 카드만). 배지 화면은 아이폰 피트니스 배지처럼 육각 메달(은색 테두리·색 에나멜·각인 띠, 미획득은 그래파이트). 메달을 누르면 검은 상세 화면에서 돌며 등장하고, 누르면 뒤집혀 뒷면(달성 날짜), 옆으로 밀면 돌아갑니다.
- **어디서 타를 잃나**: 통계 화면. OB(×2)·해저드·3퍼트 이상·티샷 미스·파3의 라운드당 평균 손실을 큰 순서로, 1위에 연습 처방. 홈의 "타수 잃는 곳" 카드도 상세 기록 라운드가 3개 이상이면 같은 1위 원인을 제목으로 보여 줍니다.
- **라운드 미션**: 새 라운드에서 하나 선택(OB 2개 이하·슬라이스 3개 이하·훅 3개 이하·3퍼트 2개 이하·페어웨이 50% 이상·더블 이상 4개 이하·목표 타수). 플레이 화면에 진행 상황, 라운드 화면·목록에 달성 표시, 통계에 미션별 달성률과 구질 추이 그래프. `mission:{type,target}`로 저장.
- **이미지로 공유**: 라운드 화면 → 1080×1920 스코어카드 PNG. 공유 시트가 되면 공유, 아니면 저장.
- **체험용 예시 라운드**: 더보기에서 예시 라운드 3개를 만들고 지울 수 있습니다(`demo:true`).

분석용 라운드: `eligibleRounds()` = 완료 + 18홀 홀별 기록 + 모든 홀 파를 앎. 스코어만 쓰는 기능(베스트·스코어 배지·누적)은 `scoreRounds()` = 총타만 기록한 18홀 라운드 포함. 고스트·브리핑은 같은 9홀 코스 기록이면 9홀 라운드도 씁니다.

## 9홀 라운드
새 라운드에서 "9홀"을 고르면 9개 홀만 입력합니다(홀별 또는 총타만). 9홀 라운드는 기록 목록에 "9홀" 표시로만 남고 평균·베스트·추이·분포·퍼팅·적중률·구질 등 모든 통계에서 빠집니다.

## 과거 기록 가져오기 (더보기 → 기록 가져오기)
아래 형식의 JSON 파일을 고르면 라운드를 한 번에 추가합니다. 날짜·골프장·총타가 같은 라운드가 이미 있으면 건너뜁니다.
홀별 파를 모르면 `par`를 `null`로 두고 `d`(파 대비 점수)만 넣으면 됩니다. `holes`를 빼고 `total`만 넣으면 총타만 기록한 라운드가 됩니다.

```json
{"format":"golf-scorebook-import-v1","rounds":[
  {"date":"2023-03-26","club":"강화웰빙CC","front":{"course":"웰빙"},"back":null,"holesPlayed":9,"tee":"White",
   "holes":[{"par":null,"d":2},{"par":null,"d":2},{"par":null,"d":3},{"par":null,"d":1},{"par":null,"d":3},
            {"par":null,"d":0},{"par":null,"d":1},{"par":null,"d":1},{"par":null,"d":2}],
   "total":51,"par":36}
]}
```
