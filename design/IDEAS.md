# 재미·시각 효과 아이디어 노트 (Claude Code와 주고받는 문서)

이 문서는 "나의 골프 스코어북"을 **더 보기 좋고, 더 재미있게** 만들 아이디어를 모아 두는 곳입니다.
라운드마다 아이디어를 덧붙이고, 고른 것은 상태를 바꿔 가며 구현합니다.

---

## 0. 이 문서 쓰는 법

1. 새 Claude Code 세션에서 아래 **"다음 라운드 요청문"**(6장)을 그대로 붙여 넣습니다.
2. Claude Code가 이 문서와 `README.md`, `index.html`을 읽고 **새 아이디어를 7장 아래에 "라운드 N"으로 추가**합니다.
3. 마음에 드는 것은 8장 표의 상태를 `하자`로 바꾸고 "○번 만들어 줘"라고 하면 됩니다.

---

## 1. 지금 앱에 이미 있는 것 (다시 제안하지 말 것)

- 고스트 매치(같은 코스 과거 기록과 홀마다 대결), 홀 브리핑(그 홀 과거 기록·코치 팁)
- 배지: 육각 메달, 누르면 돌며 등장·뒤집기, 새 배지·개인 베스트 때 꽃가루
- 라운드 미션(OB·슬라이스·3퍼트 등 목표) + 미션 메달
- 분석: 기간별 평균 그래프, 티샷 방향, "어디서 타를 잃나", 자세히(구질 분포 등)
- 라운드 기록 4탭(요약·스코어·샷·일기), 1080×1920 스코어카드 이미지 공유
- 홈·분석·코스·배지 화면 머리 사진, 시작 화면 사진

## 2. 기록되는 데이터 (새 아이디어는 이것만으로 계산)

- 라운드: 날짜, 골프장, 전반/후반 코스, 티, 9/18홀, 입력 방식(홀별 / 홀별 타수만 / 총타만), 미션, 고스트 설정
- 홀: 파(`par`), 파 대비 타수(`d`), 퍼팅 수(`putts`), 페어웨이(`fw`: 적중/왼쪽/오른쪽), 구질(`shape`), OB(`ob`), 해저드(`hz`), 메모(`memo`)

## 3. 꼭 지킬 것 (`design/v3/HANDOFF.md` 1장 요약)

- **라운드 중 입력 속도가 최우선**: 평범한 홀은 "다음 홀" 한 번으로 끝. 연출이 입력을 막거나 늦추면 안 됨(언제든 탭으로 건너뛰기).
- **저장 형식 변경 금지**: 새 기능은 기존 데이터로 계산. 꼭 필요한 기기 전용 값만 `localStorage`(예: 다음 라운드 미션).
- 단일 `index.html`, 빌드 도구 없음, 외부 라이브러리 추가 금지(Firebase·글꼴만). 오프라인 동작 유지(새 이미지는 `sw.js` 캐시에).
- 애니메이션은 **transform/opacity만**(아이폰 사파리에서 끊김 없게), `prefers-reduced-motion`이면 연출 생략.
- 좌타 기준 방향, 9홀 라운드는 통계 제외, 라이트/다크 모두, 폭 375–430px, 터치 44px 이상.
- 재미 기능은 더보기 → "재미 기능"에서 끌 수 있게.

## 4. 라운드 1 아이디어 (2026-10-22)

난이도: ★ 반나절 · ★★ 하루 · ★★★ 이틀 이상

### A. 시각 효과

**1. 라운드 끝 "스코어 리빌"** ★★ · 추천
마지막 홀을 저장하면 18개 홀 칩이 앞에서부터 차례로 뒤집히며 색(버디 파랑·파 회색·보기 주황…)을 드러내고, 가운데 총타가 0부터 올라가며 멈춥니다. 이어서 "고스트보다 3타 앞", "미션 성공", "시즌 베스트" 같은 한 줄이 순서대로 뜹니다. 탭하면 바로 끝까지 건너뜁니다.
- 데이터: `d`, 고스트·미션 결과(이미 계산함)
- 구현: 기존 꽃가루·배지 카드 연출 앞에 끼우는 전체 화면 오버레이. `rotateY` + 지연(`animation-delay`)만 사용.

**2. 홀 결과 순간 연출** ★
스코어를 고를 때 버디 이하면 숫자가 톡 튀고 초록 링이 한 번 퍼지며, 이글은 금색 반짝임이 들어갑니다. 더블 이상은 숫자가 살짝 가라앉는 정도로만(기분 나쁘지 않게) 처리합니다. 0.3초 안에 끝나 입력을 막지 않습니다.
- 데이터: 고른 스코어
- 구현: 버튼에 클래스 하나 붙였다 떼기(`scale`, `opacity`).

**3. 티샷 탄착군 지도** ★★
분석 → 티샷 방향 카드를 페어웨이 일러스트(위에서 본 그림) 위에 점을 흩뿌린 모양으로 보여 줍니다. 페어웨이 적중은 가운데, 왼쪽/오른쪽 미스는 러프 쪽, 구질에 따라 점이 휘어진 쪽에 몰립니다. 기간을 바꾸면 점들이 새 자리로 미끄러집니다. 좌타 기준.
- 데이터: `fw`, `shape`, `ob`
- 구현: 인라인 SVG 고정 그림 + 점은 HTML 요소에 `transform`으로 위치(움직이는 SVG 금지 규칙 때문).

**4. 시즌 잔디 달력** ★
GitHub 잔디처럼 1년치 달력에 라운드 친 날을 칠합니다. 색 진하기 = 그날 스코어(좋을수록 진한 초록), 개인 베스트 날은 금색 칸. 누르면 그 라운드로 이동.
- 데이터: 날짜, 총타
- 구현: 분석 화면 맨 위나 홈 최근 라운드 위, CSS grid 7×53칸.

**5. 시간대별 머리 사진 분위기** ★
홈 머리 사진 위 그라데이션을 시간에 따라 바꿉니다: 새벽 티오프(푸른빛), 낮(그대로), 해 질 녘(주황빛), 밤(어둡게). 라운드 진행 중이면 사진 대신 진행 중인 홀 번호를 크게 겹쳐 보여 줍니다.
- 데이터: 기기 시계, 진행 중 라운드
- 구현: `.phead::after`의 그라데이션 색만 교체.

### B. 게임 요소

**6. 고스트 라이브 레이스 바** ★★ · 추천
플레이 화면 위에 가로 진행 바를 두고, 내 골프공과 고스트 공(반투명)이 홀마다 앞으로 굴러갑니다. 공 위치 = 지금까지 파 대비 타수. 앞서면 내 공이 초록으로 빛나고, 역전하는 순간 짧은 "역전!" 표시가 뜹니다.
- 데이터: 기존 `ghostDiff` 결과
- 구현: 공 두 개를 `translateX`로 이동. 고스트가 없는 라운드면 숨김.

**7. 골퍼 레벨(경험치)** ★★
라운드·버디·파 세이브·미션 성공에 경험치를 주고 "루키 → 아마추어 → 보기 플레이어 → 싱글 → 스크래치" 레벨로 올라갑니다. 홈 인사 아래 얇은 경험치 바, 레벨이 오르면 배지 카드처럼 축하 연출.
- 데이터: 전부 기존 라운드에서 다시 계산(배지처럼 저장하지 않음 → 기록을 지우면 자동 반영)
- 구현: `computeBadges()`와 같은 방식의 `computeLevel()`.

**8. 코스 정복 지도** ★★★
코스 화면 → 골프장 → 코스마다 9홀을 칸으로 그리고, 내 베스트 결과로 색칠합니다(버디 이상 파랑, 파 초록, 보기 이하 회색). 모든 홀을 파 이상으로 친 적이 있으면 그 코스 "정복" 깃발. 다음에 갈 때 "아직 파를 못 한 홀 3개" 같은 목표가 생깁니다.
- 데이터: 코스별 홀 기록(고스트·브리핑과 같은 매칭)
- 구현: 기존 홀 브리핑 계산 재사용.

**9. 오늘의 도전 카드 뽑기** ★
새 라운드 화면에서 뒷면 카드 3장 중 하나를 뒤집으면 미션이 무작위로 나옵니다(최근 약점 쪽에 가중치: OB가 많았으면 "OB 2개 이하"가 자주 나옴). 고르면 기존 미션 칸에 그대로 채워집니다.
- 데이터: 기존 미션 목록 + "어디서 타를 잃나" 1위 원인
- 구현: 저장 형식 그대로(`mission`).

**10. 연속 기록(스트릭) 알림** ★
라운드 중 "3홀 연속 파 이상", "6홀째 3퍼트 없음" 같은 연속 기록이 생기면 플레이 화면 위에 작은 불꽃 칩이 뜨고 숫자가 올라갑니다. 끊기면 조용히 사라집니다. 라운드 끝에 그날 최장 스트릭을 리빌(1번)에 포함.
- 데이터: `d`, `putts`, `fw`

### C. 돌아보기·이야기

**11. 연말 결산 "스코어북 랩"** ★★★ · 추천
Spotify Wrapped처럼 화면을 넘기는 이야기 카드: "올해 18라운드, 1,642타", "가장 많이 간 골프장", "최고의 홀", "가장 좋아진 것: 3퍼트 −40%", "올해의 한 라운드". 마지막 장은 공유 이미지(기존 1080×1920 공유 기능 재사용). 12월~1월에 홈 위에 띠로 등장.
- 데이터: 그 해의 라운드 전부

**12. 라운드 한 줄 하이라이트** ★
라운드 기록 요약 탭 맨 위에 규칙으로 만든 한 줄 이야기: "후반 3연속 파로 반등", "파3에서만 4타 잃음", "드라이버가 춤춘 날(OB 3)". 홈 최근 라운드 목록에도 작게.
- 데이터: 홀 기록 전부, 규칙 기반(인공지능 호출 없음)

**13. 다음 목표 링** ★
홈 평균 카드 옆에 "다음 라운드 ○○타 이하면 5라운드 평균 신기록" 같은 링 게이지. 목표까지 가까울수록 링이 찹니다.
- 데이터: 최근 라운드 평균 계산(이미 있음)

**14. 효과음 (기본 끔)** ★
버디 "팅", 배지 획득 "짠", 라운드 끝 박수 같은 짧은 소리. 파일 없이 Web Audio로 합성해서 오프라인·용량 문제 없음. 아이폰 무음 모드면 자동으로 안 남. 더보기 → 재미 기능에서 켜기.
- 참고: 아이폰 사파리는 진동(Vibration API)을 지원하지 않아 진동은 불가.

### 라운드 1 추천 순서
1번 스코어 리빌 → 6번 고스트 레이스 → 2번 홀 결과 연출 → 11번 연말 결산(12월 전에)
이유: 1·6·2는 매 라운드 체감되고 저장 형식을 건드리지 않으며, 11은 시기가 정해져 있음.

## 6. 다음 라운드 요청문 (Claude Code에 그대로 붙여 넣기)

```
design/IDEAS.md를 읽고, README.md와 index.html도 훑어서 지금 앱 상태를 파악해 줘.
그다음 이 문서 7장 아래에 "라운드 N (날짜)" 제목으로 새 아이디어 8~10개를 추가해 줘.

조건:
- 1장(이미 있는 것)과 4장·7장(이전 라운드)과 겹치지 않을 것. 이전 아이디어를 발전시키는 건 OK(몇 번을 발전시킨 건지 적기).
- 3장 "꼭 지킬 것"과 2장 데이터만으로 가능할 것. 불가능하면 왜 안 되는지 한 줄로.
- 각 아이디어: 제목, 난이도(★~★★★), 무엇이 보이나(장면 묘사), 쓰는 데이터, 구현 메모.
- 5장 기준으로 스스로 점수를 매겨 추천 3개와 이유를 적을 것.
- 8장 표에 새 아이디어를 "후보" 상태로 추가할 것.
- 코드는 아직 고치지 말고 문서만 커밋해 줘.
```

구현을 맡길 때:

```
design/IDEAS.md의 ○번 아이디어를 만들어 줘. 3장 규칙을 지키고,
tools/shot.mjs로 라이트/다크 스크린샷 확인, tools/flow-test.mjs 통과시킨 뒤
README에 기능 설명 추가하고 8장 표 상태를 "완료(vNN)"로 바꿔 줘.
```
