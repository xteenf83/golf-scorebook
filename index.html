재미 기능

백업

모든 라운드를 홀별로 정리한 CSV 파일로 저장합니다. 엑셀·넘버스에서 열 수 있어요.

기본 코스

앱에 들어 있는 기본 코스 목록(현재 개)으로 내 코스를 다시 맞춥니다. 같은 골프장·코스가 있으면 홀별 파만 덮어쓰고, 없으면 새로 만듭니다. 직접 추가한 다른 코스는 그대로 둡니다.

기록 가져오기

예전 기록을 JSON 파일로 한 번에 넣습니다. 버튼을 누르고 아이폰 ‘파일’ 앱에서 파일을 고르세요. 날짜·골프장·총타가 같은 라운드가 이미 있으면 중복으로 보고 건너뜁니다.

체험용 예시 라운드

고스트·홀 브리핑·배지를 미리 보려면 서원힐스CC 웨스트·사우스로 예시 라운드 3개를 만듭니다. 예시 라운드도 통계·배지에 들어가니 확인한 뒤 꼭 지워 주세요. (목록에 ‘예시’ 표시)

저장 방식 · 앱 정보

기록은 클라우드에 저장되어 폰을 바꾸거나 앱을 지워도 남아 있습니다. 본인 계정만 읽고 쓸 수 있습니다. 필드에서 신호가 약하면 폰에 먼저 저장했다가 연결되면 자동으로 올라갑니다.

앱 버전 · 새 버전이 나오면 앱을 열 때 자동으로 바뀝니다.

총 타수로 라운드 저장

홀별 점수를 다 챙기지 못했을 때 사용하세요. 이 라운드는 스코어 통계(평균·베스트·추이)에만 들어가고, 지금까지 입력한 홀별 기록은 사용되지 않습니다.

배지

코스를 바꾸면 해당 9홀의 파가 새 코스 기준으로 바뀝니다. 이미 입력한 결과(보기·퍼팅·구질 등)는 그대로 유지돼요.

코스

골프장을 누르면 코스별 홀 파를 확인하고 고칠 수 있습니다. 새 골프장은 Claude에게 이름만 알려주면 앱 업데이트로 자동 등록해 드립니다.

코스 직접 추가

홀별 파는 기준정보라 실수로 바뀌지 않게 잠겨 있어요. 골프장 코스가 바뀌었을 때만 수정을 눌러 고치고 저장하세요.
